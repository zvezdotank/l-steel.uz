# Website UI kit

Click-through recreation of lizhong-steelstructure.com's public marketing site: Home, About Us, Product and Contact, using the design system's Navbar, Button, Card, Tag and Input components. FACTORY and NEWS are in the nav but not built out as screens (no imagery/content source was accessible — see root readme.md caveats).

Nav links in `index.html` are wired with a click handler that swaps the active screen; this is a click-through mock, not a router.
