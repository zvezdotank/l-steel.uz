Action button in four variants; used for the primary "Quote Now" CTA (accent) and secondary navigation/submit actions.

```jsx
<Button variant="accent">Quote Now</Button>
<Button variant="primary">Submit Inquiry</Button>
<Button variant="secondary">View Catalog</Button>
<Button variant="ghost">Learn more →</Button>
```

Labels are always flush-left, uppercase, letter-spaced — never centered, even on `block` buttons.
